## New challenge distinctions carried by this review

also requires distinctions that a contradiction-only challenge misses:

| Challenge | Positive carrier | Failure contrast |

| Claims agree across surfaces | Plan title/edges, surfacer title, sweep dependency and verdict type are maintained | Qualify content but leave an unsupported title, edge or type |

## Deliberate tensions and limits

- **Shared conflict, held constant:** the unchanged gist requires a first
  reply with a tool call and describes read → write → close rigidly; the
  templates also allow legitimate zero-work skips and another repair write.
  The cue strategy reinforces result inspection but does not fix this shared
  conflict. Track lists-then-stop and repair rounds in eval; don't attribute
  them solely to compression. Any gist revision is a separately labeled set.
- **Unfixed input limitation:** prose about fetching residue/edge-only IDs
  cannot make missing IDs visible. Catalog rendering and its shared gates
  remain Tom's decisions. No new fetch result is claimed here.
- **Coupled treatment:** cue arms test local pointers plus final strategy
  together. They cannot attribute an effect to either component alone.
- **Unequal section counts:** full v2 has 38 cued authored headings; v3 has
  27. Corresponding sections use the same pointers; compressed grouping
  naturally changes where/how many cues exist.
- **Intentional overlap:** cues restate each section's job; the strategy
  restates the overall procedure at the end. This is the explicit attention
  treatment. No unrelated cuts compensate for its cost.
- **Original examples:** identity and relation teaching still includes
  figurative phrasing, inferred meaning and illustrative placeholders. The
  review does not replace that stance with fact-only storage. Literal
  placeholder leakage remains a behavioral outcome to inspect.
- **Historical contamination:** the already-developed sweep resembles the
  gold repair task, and v2's earlier teaching scene was close to the synthetic
  diagnostic. Framing avoids that diagnostic's classroom surface. This does
  not erase inherited overlap or establish held-out generalization. Wider
  independent corpus validation remains necessary.
- **Verification scope:** JSON call blocks plus the sweep and revision ladder
  receive field/structural checks and selected swap simulation. Other teaching
  fences include illustrative pseudo-code and slots. This is not complete
  JSON Schema validation or actual dispatch, and no prompt behavior is proved.
- **Runner integration pending:** the sealed loader returns composed systems
  and an arm identity. Existing corpus runners are not yet wired to consume
  them. Check actual outgoing request, cache identity and read substrate before
  the next model cell. Template-only overrides lose the ending placement.

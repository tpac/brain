## The goal, in Tom's words

Stop the strong boundary between `encoded="true"` and `encoded="false"` across the prompt.

The encoder's input marks each turn of its window as covered by an earlier run (`true`) or not (`false`). Today the
prompt treats that flag as a hard line: uncovered turns are the material, covered turns are done. The work is to
make the prompt read both kinds of turn as one conversation, balanced, with the flag as information about what an
earlier run did rather than a boundary on what this run may do. The rewrite is symmetric: it says what the encoder
reads and does across the whole window, not "stop skipping covered turns".

## How to evaluate the rewrite

Yes — this round is authored **and** measured. The order is a gate, not a preference: draft with Tom, paragraph by
paragraph → his marks → freeze → static checks → only then spend. Nothing is measured before it is frozen, and
nothing is frozen before Tom has marked the text. A cell costs real money and an hour, and a candidate that moves
after a number is a candidate with no number.

Method: `docs/S1E-EVAL-PROTOCOL.md`, run from a worktree with `./dev python3`. Instruments live in the V3.8 fixture
(copied from V3.7; repoint the `v3_7`/`v37` references — `grep -n "v3_7\|v37"`).

1. Before authoring: record a fresh transfer split by id (`transfer_split.json`; two items per LongMemEval type;
   the gym item 59524333 goes to regression only). Write `ANALYSIS.md`: arms, targets, guards.
2. Targets for this class: knowledge-update items answered from a node stating the current value; encoding runs
   that revise an `encoded(me, …)` node when covered text changed; zero-write runs on windows that held an uncovered
   fact or a changed value.
3. Guards (uncovered-turn quality must not fall): question fill per repeat, nodes per window, first-disclosure facts
   kept, fabricated and overclaimed shares, near-twin pairs, revise ops on nodes whose covered text did not change.
4. Freeze through `arms.py --build-check` / `--freeze` (assembly byte-for-byte what a merge would run). Fresh cell
   with a same-day `v3_6_full` control (≈ $15–25). Longmem pair via `run_longmem_v36_v38.sh <arm> <template> [gist]`
   (≈ $15, ~1 h), per-layer read as in the V3.7 results doc § Longmem.
5. Known confound: replayed corpora render every turn `age="just now"` (`encode.py` L1130–1141) though each turn's
   text carries its real date; knowledge-update items are biased against every arm equally.
6. `replay_payload.py` replays one captured encoder request (~$0.12): a mechanics check only. Never author from a
   replayed item and never read a replay as a result.

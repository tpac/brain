## The mental model to carry (id:64abc6a0, verified against runs and code)

A miss or misread in encoder run N is never revisited by run N+1. Three mechanisms compound:

1. **The flag is by run range, not by write** — `servers/scales/s1/trace_links.py` ~L300–325: a turn's `encoded_by` is
   the first encoding_run whose stop is after it; that run's created/revised list may be empty. A zero-write run stamps
   every turn it saw as covered.
2. **The gloss** — `encoding_prompt.py` L39: `encoded="true"` means a prior run covered the turn… "I reread covered text
   for cross-turn patterns and contradictions, not fresh atoms"; L281 "Handle visible material now rather than counting on
   another run." Nothing says a covered turn whose facts have no node is uncovered material.
3. **Residue carries the verdict** — the airport item (09ba9854_abs, V3.7): run 1 "no durable memory", run 2 "turns 1–5
   already encoded as no-mint … continuation of the no-mint thread flagged in continuity", run 3 "threshold held cleanly".
   Three runs, zero nodes, catalog visibly empty. The template's "a no-mint verdict never goes to residue" (L289, L469)
   did not bind.

Plus the slide: a window rendered after a zero-write run no longer shows the earlier turns at all (fresh cell,
`v3_7_quote/repeat3/lm_07741c44`).

The worked case, gym item 59524333 (gold 6 pm): run 1 wrote 7 pm (Feb); run 2 saw "the gym, which is usually at 6:00
pm" (May) — V3.7 read it as Tuesday buffer framing and marked the node clean, V3.6 filed an in-window contradiction
inside one node instead of superseding; run 3 saw turns 2–10 as covered with the 6 pm text one screen from the 7 pm
node, and wrote nothing. Both arms fail the item.

**Eval confound (Tom confirmed):** replayed corpora render every turn `age="just now"` — the injectable brain-time moves
the `now=` stamp but not per-turn trace timestamps — so months-apart turns read as simultaneous and the contradiction
rule fires where the change rule should. Fix or account for it before reading knowledge-update items (encode.py comment
near the `age_attr` render names the cause).

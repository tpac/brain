    - Concise summaries might lose essential nuance

    2. **Deterministic decode testing**: Run queries against frozen snapshot. Same database state = same cosine similarities = identical NDCG/MRR scores every time. Can test hundreds of query variations without variance.
    
    3. **Version comparison**: Compare brain_v5_snapshot.db vs brain_v6_snapshot.db on identical query sets. Isolates the impact of encoding changes.

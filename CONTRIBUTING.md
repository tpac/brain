# Contributing

Thanks for your interest in Entity.

**Issues are the channel.** Bug reports, questions, and ideas are all welcome
as GitHub issues. Pull requests are not being accepted right now — the
project is developed against a private tree and published as releases, so a
PR here has nothing to merge into. If that changes, this file will say so.

A good bug report includes:

- what you did, what you expected, what happened
- your platform (macOS / Linux) and Claude Code version
- relevant lines from the daemon log — but **read them before pasting**:
  logs can quote your conversations and your memories

**Never paste memory content you wouldn't publish.** Your brain is yours;
issue threads are forever.

Security reports: open an issue asking for a private channel — don't put
the details in the issue itself.
